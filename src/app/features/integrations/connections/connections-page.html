Como funciona

As conexões acima não guardam senha nem token neste app: o estado é local, em localStorage, e serve para mostrar a arquitetura. Só o Supabase é real — ele é derivado das variáveis de ambiente, e a cotação da BrAPI é a única chamada de rede do app. Nenhuma chave é enviada para o frontend.
